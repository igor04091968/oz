# Аудит CentOS 5 Xen перед переносом на Debian

Скрипт `audit-centos.sh` предназначен для запуска на старом CentOS 5/Xen с
ядром `2.6.18-194.26.1.el5xen`.
Он не устанавливает пакеты и не меняет конфигурацию. В отчет попадают только:

- работающие и включенные SysV-сервисы через `service` и `chkconfig`;
- systemd-сервисы, только если systemd неожиданно присутствует;
- слушающие порты, процессы, маршруты и firewall;
- mountpoints, cron-задачи и xinetd;
- фактические sysctl, загруженные модули ядра, modprobe, limits и SELinux;
- параметры Xen (`xm`/`xl`, `/proc/xen`);
- пакеты-владельцы исполняемых файлов активных процессов.

Полный список установленных RPM намеренно не собирается.

## Запуск

```bash
chmod +x audit-centos.sh
sudo ./audit-centos.sh /var/tmp/centos-audit
```

Скрипт не требует systemd и использует доступные в CentOS 5 команды
`ifconfig`, `route`, `netstat`, `service`, `chkconfig` и `sysctl`.

Если каталог не указан, он создается рядом со скриптом. На выходе создаются:

- каталог с отдельными текстовыми файлами;
- архив `centos-audit-*.tar.gz` с правами `600`.

Значения, похожие на пароли, токены, ключи и Authorization-заголовки,
маскируются как `[REDACTED]`. Перед передачей отчета все равно проверьте его
вручную. На основе отчета следует составить отдельный Debian-план, а не
переносить каталог `/etc` целиком.
